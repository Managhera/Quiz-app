<h1>🧠 Quiz App </h1>  
A responsive and interactive Quiz Web Application developed by Aghera Man. This project provides a seamless platform for users to test their knowledge on various topics. It supports dynamic quiz generation, real-time feedback, and a user-friendly interface suitable for all screen sizes.
